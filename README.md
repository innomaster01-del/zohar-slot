# ZOHAR — אפליקציית אנדרואיד (APK)
המשחק רץ מתוך האפליקציה, בלי אינטרנט. כסף משחק בלבד.
- בנייה אוטומטית: דחיפה ל-GitHub מפעילה את `.github/workflows/build-apk.yml`, וה-APK מופיע ב-Actions → Artifacts.
- בנייה ב-Android Studio: File → Open על התיקייה → Build → Build APK(s).
- התקנה: מעבירים את zohar-slot.apk לטלפון, פותחים, ומאשרים "התקנה ממקורות לא ידועים".
הגבלה: WebView של אנדרואיד לא תומך ב-WebXR, לכן באפליקציה אין העמדה על הרצפה. יש משחק מעל המצלמה ומצב תלת-ממד.
העמדה על הרצפה עובדת בגרסת האתר בכרום.
